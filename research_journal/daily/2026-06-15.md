# 2026-06-15

## Strategy B query bug — Llama parroted the prompt example (caught by Ankit)
- **Symptom:** two different leaves (a dark leaf-spot image and an apple-scab leaf) produced near-identical queries, both describing "scorched leaves with whitish spots". Ankit suspected the disease type wasn't reaching Llama, or the phrase was hardcoded.
- **Root cause (confirmed in code):** the disease label *was* being injected — `strategy_llm_mediated.py::_build_prompt` line ~133 puts `Vision-detected disease (modern label): {disease}` in the prompt. But the **system prompt's Rule 3 carried a single concrete example** — `'scorched leaves with whitish spots'` — and Llama was **copying that example verbatim** instead of translating the actual disease (few-shot example leakage / anchoring). So: data present ✅, but the bridge dropped it ❌.
- **Why it matters:** every disease collapsed to the same phrase → retrieval can't differentiate diseases → undercuts the whole vision→IKS bridge novelty.
- **Fix:** rewrote `_SYSTEM_INSTRUCTIONS` Rule 3 to (a) demand the symptoms of the EXACT named disease, and (b) replace the one leaky phrase with a **symptom-family map keyed by disease keyword** (rust→pustules, scab→corky lesions, powdery mildew→white coating, blight→necrotic patches, leaf spot/Septoria→ringed spots, mold→fuzzy patches, rot→sunken decay, mosaic/virus→mottled discoloration, mite→stippling) + explicit "do NOT reuse a phrase for a disease it does not fit." Soil moved to a generic descriptive instruction (no single parroted "fertile riverine soil").
- **Validated:** prompt now contains the disease line, the leaky example is gone, the scab guidance is present; 15 integration tests pass.

## Crop dropdown — keep manual selection as the human override
- Ankit's point: if the vision model misreads the plant type, the human's dropdown pick should be the final truth — so don't remove selection. Current app behaviour already supports this: dropdown defaults to **"auto"** (derive crop from the detected disease label) but any explicit pick **overrides** the detection. No change needed; confirmed the design is right.
